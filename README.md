# LOS Calculator

Android app to calculate Radio Horizon and Line Of Sight between two antennas.

## Features
- Calculate Radio Horizon
- Support meters and feet
- Built with Jetpack Compose

## Formula

D = 3.57(√h1 + √h2)

## Tech
- Kotlin
- Jetpack Compose
- MVVM
